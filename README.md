# AI金融决策智能体 (AI Finance Agent)

自主感知 · 多维分析 · 智能决策 — 面向个人投资者的 AI 投研助手。

## 核心能力

| 模块 | 说明 |
|------|------|
| **单股深度分析** | 28 因子综合量化评分 + 5 维度分层报告 |
| **全市场扫描** | 5499 只 A 股实时扫描 · 市场仪表盘 · 风险标注 |
| **量化风险** | VaR / 夏普比率 / 凯利公式 / 最大回撤 |
| **操作建议** | 具体买卖触发价位 + 止损止盈 + 仓位建议 |

## 技术架构

```
app.py              # Streamlit Web 界面
quant_engine.py     # 综合量化分析引擎 (28因子 + Piotroski + 风险量化)
data/quotes.py      # 腾讯财经行情数据层 (零依赖)
```

### 28 因子体系

| 维度 | 因子数 | 核心策略 |
|------|--------|---------|
| 趋势研判 | 8 | SMA 多周期 / MACD / ADX / 布林带 / 一目均衡 / Donchian |
| 动量信号 | 6 | RSI(背离) / KD / CCI / 威廉%R / ROC / 多周期动量共振 |
| 波动风险 | 5 | ATR 百分位 / 历史波动率 / 布林带 Squeeze / Beta / 回撤 |
| 资金流向 | 5 | OBV / MFI / Chaikin / 量比 / VPT |
| 形态识别 | 4 | K 线形态 / 支撑阻力 / 斐波那契 / 缺口 |

### 量化风险指标

- 年化收益率 / 波动率
- 夏普比率 / 索提诺比率 / 卡玛比率
- VaR (95%, 99%)
- 最大回撤
- 胜率 / 盈亏比
- 凯利公式仓位建议

### 基本面

- Piotroski F-Score (9 分制价值评估)
- 财务摘要 (ROE / 毛利率 / PE / PB / 资产负债率)

## 快速开始

**Python 版本要求: >= 3.10**

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动
streamlit run app.py --server.port 8501

# 3. 打开浏览器
# http://localhost:8501
```

> ⚠️ **端口占用**: 如果 8501 端口已被占用，可指定其他端口启动：
> ```bash
> streamlit run app.py --server.port 8502
> ```
>
> ⚠️ **首次启动提示**: akshare 首次运行时会自动下载股票列表等基础数据，可能需要等待 10-30 秒，后续启动将使用缓存数据，速度更快。

## 使用说明

### 单股分析
1. 在「单股分析」标签页输入股票代码（如 `600036`）或名称（如 `招商银行`）
2. 点击「开始分析」
3. 查看完整的 28 因子量化报告，包含：
   - 综合评分 & 评级 (AAA~CCC)
   - 因子信号分布 (看涨/看跌/中性)
   - 五维度深度分析 (每因子具体数值与解读)
   - 量化操作条件 (具体买卖触发价位)
   - 风险量化面板
   - K 线图 (含均线、支撑阻力线)
   - 财务摘要 & 新闻情感

### 全市场扫描
1. 切换到「全市场扫描」标签页
2. 点击「快速扫描」(200 只, 5-10 秒) 或「全市场扫描」(5499 只, 90-120 秒)
3. 查看市场情绪仪表盘、涨跌分布、强势/弱势个股列表
