## 1. 购买腾讯云服务器

### 推荐配置

| 配置项 | 推荐值 | 说明 |
|-------|--------|------|
| 机型 | 轻量应用服务器 | 新手友好，价格便宜 |
| 地域 | 离你最近的城市 | 选广州/上海/北京均可 |
| 配置 | **2核2GB** | 够用，预算够可上 2核4GB |
| 系统盘 | **40GB SSD** | 足够 |
| 带宽 | **5Mbps** | 演示够用 |
| 镜像 | **Ubuntu 22.04** | ⚠️ 请务必选这个 |
| 时长 | 1个月 | 比赛期间够用，约 **68元/月** |

### 购买步骤

1. 打开 https://cloud.tencent.com
2. 注册/登录（微信扫码即可）
3. 顶部菜单 → **产品** → **轻量应用服务器**
4. 点击「立即购买」
5. 按上表选择配置

   > 🔑 **关键：镜像选「Ubuntu 22.04」，不要选 CentOS**

6. 设置登录密码（**记下来！** 建议截图保存）
7. 提交订单 → 付款
8. 等 1-2 分钟，服务器就创建好了

### 找到服务器信息

购买完成后：

1. 进入 [腾讯云轻量应用服务器控制台](https://console.cloud.tencent.com/lighthouse/instance)
2. 你会看到你的服务器卡片，上面有：
   - **公网 IP**（一串数字，比如 `1.2.3.4`）
   - **状态**（显示「运行中」才是正常的）

## 2. 登录服务器

### Windows 用户（推荐用 PowerShell）

1. 打开 PowerShell（Win键 → 输入 `powershell` → 回车）
2. 输入以下命令（把 IP 换成你的）：

```powershell
ssh root@你的服务器IP
```

比如你的 IP 是 `1.2.3.4`，就输入：

```powershell
ssh root@1.2.3.4
```

3. 第一次连接会提示确认，输入 `yes` 回车
4. 输入你买服务器时设置的密码（输入时屏幕不会显示，正常）
5. 看到类似这样的提示，说明登录成功：

```
Welcome to Ubuntu 22.04 LTS
root@vm-xxxx:~#
```

## 3. 一键部署项目

登录服务器后，在命令行（黑窗口）里按顺序执行以下命令：

### 第1步：安装 Git

```bash
apt-get update && apt-get install -y git
```

### 第2步：下载项目代码

```bash
cd /root
git clone https://github.com/qq1009128320-dotcom/ai-finance-agent.git
```

### 第3步：运行一键部署脚本

```bash
cd ai-finance-agent
sudo bash deploy/install.sh
```

> 这一步会自动完成所有安装，需要 **3-5 分钟**，耐心等待。

如果一切顺利，最后会显示：

```
============================================
  🎉 部署完成！
============================================

  访问地址: http://你的服务器IP
  API文档:  http://你的服务器IP/docs
```

## 4. 配置 API 密钥

项目需要 DeepSeek API 密钥才能使用 AI 策略生成功能。

### 获取 DeepSeek API 密钥

如果你还没有：
1. 打开 https://platform.deepseek.com
2. 注册登录
3. 左侧菜单 → API Keys → 创建新的 Key
4. 复制生成的密钥（一串以 `sk-` 开头的字符串）

### 填写密钥

在服务器命令行中执行：

```bash
cd /root/ai-finance-agent
nano .env.production
```

会打开一个编辑界面。你会看到：

```
DEEPSEEK_API_KEY=你的API密钥
PRODUCTION=true
```

把 `你的API密钥` 替换成你复制的真实密钥。

> **如何保存退出 nano：**
> 1. 按 `Ctrl+X`（退出）
> 2. 按 `Y`（确认保存）
> 3. 按 `回车`（确认文件名）

### 重启服务使配置生效

```bash
sudo systemctl restart ai-quant
```

## 5. 服务器防火墙设置

### 为什么需要这一步？

腾讯云默认**不开放** 80 端口，需要手动设置。

### 操作步骤

1. 打开 [腾讯云轻量应用服务器控制台](https://console.cloud.tencent.com/lighthouse/instance)
2. 点击你的服务器卡片
3. 左侧导航 → **防火墙**
4. 点击「添加规则」
5. 按如下填写：

| 字段 | 值 |
|------|-----|
| 应用类型 | HTTP(80) |
| 协议 | TCP |
| 端口 | 80 |
| 来源 | 0.0.0.0/0 |

6. 点击「确定」

> 等待 1-2 分钟生效。

## 7. 日常维护

### 查看服务状态

```bash
sudo systemctl status ai-quant
```

### 查看实时日志

```bash
sudo journalctl -u ai-quant -f
```

按 `Ctrl+C` 退出日志查看。

### 重启服务

```bash
sudo systemctl restart ai-quant
```

### 更新代码

如果本地有代码更新，在服务器上执行：

```bash
cd /root/ai-finance-agent
git pull
sudo systemctl restart ai-quant
```

## 8. 常见问题

### 浏览器打开显示「无法访问此网站」

原因通常是 **防火墙没设置**，请看第5步检查腾讯云防火墙。

### 页面显示了但没有数据（表格空白）

后端需要几秒钟初始化数据，刷新一下试试。如果还是空白，查看日志：

```bash
sudo journalctl -u ai-quant -n 30 --no-pager
```

### DeepSeek API 报错

检查 `.env.production` 中的 API 密钥是否正确填写，然后重启服务。

### 忘记服务器密码

去腾讯云控制台 → 你的服务器 → 更多 → 重置密码

### 想用域名访问

可以买个域名（如 `ai-quant.com`），在腾讯云 DNS 解析里设置 A 记录指向你的服务器 IP。需要帮助的话可以找我。
